# Bienvenid@ al Nexo 🤖

Te han encargado que hagas exactamente esta interfaz web para que los usuarios entren en el sistema de Nexo.

El formulario consta de 3 partes diferentes:

- Mensaje de bienvenido e introducción del nombre de usuario
- Mensaje de correo electrónico y el campo para introducirlo
- Mensaje para introducir la contraseña y el campo para introducirla
- Una último apartado donde aparece toda la información que se ha ido introduciendo durante el proceso



## 👀 Requisitos mínimos de corrección de la prueba

- No puede haber errores en consola
- Tiene que existir código `HTML`, `CSS` y `JS`
- Nada de IA ni de cualquier ayuda externa
- Como mínimo, la funcionalidad tiene que estar al 100%

```bash
En cuanto no se cumpla ALGUNA de las 4 condiciones anteriores, el examen estará completamente suspendido
```



## 💯 Puntuación máxima

- Estructura `HTML`: 2️⃣ puntos
- Diseño `CSS` idéntico (con algunas excepciones) de la aplicación: 2️⃣ puntos
- Funcionalidad `JS` correcta: 3️⃣ puntos
- Animación de galaxias lejanas: 2️⃣ puntos
- Estructura del proyecto con sentido: 1️⃣ punto
